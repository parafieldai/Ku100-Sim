How to interpret this comparison

The same common mechanical kernel generates the already-ringing sources. Frequency, damping and source geometry are parameters, not separate fork solvers. All comparisons are stereo RMS-matched with a static peak cap; the purpose is to compare the changing sound, not to prove real-world sound pressure.

Rotation is about the source itself, not a orbit around the head. The predicted close examples place the source center 3 cm outside an assumed sphere; this is not the actual gap to a silicone pinna. Neither direct contact nor bone conduction is modeled.

The curve in each card is the actual left/right audio envelope, not a slowed image of the fork's physical motion. The source begins in a declared vibrating state: this experiment does not simulate the striking tool.

Research: Russell (2000), tuning-fork quadrupole radiation; Duda & Martens (1998), rigid-sphere near-field transfer. Numerical checks validate the equations within those approximations, not a listener's ASMR response.
